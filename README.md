# Program Description
This C++ program calculates the sum of the first 50 natural numbers.

It uses two methods:
1. A for loop to add the numbers from 1 to 50.
2. The formula n(n+1)/2 to verify the result.

# Output
Sum of first 50 natural numbers (loop): 1275
Sum using formula n(n+1)/2: 1275
